# Third party notices

This repository contains no third party code, fonts, images or data copied into it. The screenshots and demo show this app only, the page uses system fonts, and the 50 test messages were written for this project.

The project depends on packages installed from npm (Fastify, React, Vite, TypeScript, tsx and what they pull in). They aren't included here and keep their own licenses. In the lockfile these are MIT, Apache-2.0, BSD-3-Clause, ISC and MPL-2.0. Each package's license text is in its folder under `node_modules` after `npm install`.
