How it works

Three steps. You stay in charge of every one.

  1. 1

    Say it the way it feels

    Start a chat, send the other person one link, and write in your own words. No accounts, no passwords, nothing to install for them.

  2. 2

    Check the calm version

    Tactful keeps your facts, dates and asks, and drops the insults. Send it, edit it, ask for another try, or cancel. Edits get checked again.

  3. 3

    They only see what you approved

    The other person gets the calm version, live, marked as rewritten. They never see your original, and it's deleted the moment you send.

Features

Built so the calm version can be trusted.

Threats get stopped, not polished

A threat doesn't get better with nicer words, so it isn't sent at all. The sender is told why, and sees where to find help if someone may be in danger.

If it fails, nothing goes

No AI answer, a timeout, a bad reply: in every case nothing is sent. Your original can't slip through by accident.

Nobody is fooled

Both people agree to rewriting before they start, and every single message carries a "rewritten" label.

One link, no accounts

Asking someone to sign up in the middle of an argument loses them. They tap a link that works once, and they're in.

Originals don't stick around

Your first draft is deleted when you send or cancel. Message text never goes into a log, and chats are deleted 30 days after they close.

Yours to run

One small Node service with SQLite. Run it on your laptop or a Linux box with one setup script. Swap in the AI provider you trust.

Install

Running in about a minute.

You need Node.js 24 or newer. It starts with the built in rewriter, so you can try everything for free before adding an AI key.

Run it on your machine
git clone __REPO_URL__.git
cd Tactful
npm install
npm run build
npm start

Open http://127.0.0.1:3000, start a chat, and open the invite link in a second window to be the other person.

Run the tests
npm test
npm run typecheck
Put it on a Linux server, with HTTPS
sudo DOMAIN=chat.example.com ./setup_service.sh
journalctl -u tactful.service -f

Run the script again any time to update and restart. Settings live in .env, and the README lists them all.

FAQ

Straight answers, including the limits.

Is the AI in the demo real?

No. The recording uses the built in rewriter, a small set of rules, so it runs free and offline. A Claude provider is in the code, but it hasn't been tried against the real API yet. You bring your own key.

Does the other person know messages are rewritten?

Yes. They agree to it before they join, and every message is labelled "rewritten". Hidden rewriting would feel like a trick, and it would be one.

Can the server read my messages?

Yes, it has to, to rewrite them. So there's no end to end encryption, and the app doesn't pretend there is. Originals are deleted once a message is sent or dropped, and message text never goes into a log.

Who is it not for?

Situations involving abuse, violence or danger. Softening messages there could hide a real risk. It's also not therapy, legal advice or mediation. It's for adults with everyday disagreements: money, housing, family, work.

Is it free?

Free for non-commercial use under PolyForm Noncommercial 1.0.0. That covers personal use, study and hobby projects, and use by charities, schools, public research bodies and government. For anything commercial, open an issue and ask.

Can I run it for other people?

For non-commercial use, yes. Plug in a real AI provider first, and fill in the privacy notice and terms templates in the app and have them reviewed. It's early software and hasn't had a security review.
