Tactful (working name)

Talk it through, calmly.

A chat for two people who have a problem to solve. You write what you want to say, in your own words. AI rewrites it into a calmer, more tactful version. You check it, and only that version reaches the other person.

See it work

How it works

  1. One person starts a chat and sends the other a link. No accounts, no passwords.
  2. You write a message, the way you would say it.
  3. AI rewrites it. You read the new version and send it, edit it, ask for another, or cancel.
  4. The other person only ever sees the rewritten version, marked as rewritten.

It's for adults with everyday disagreements: money, housing, family, work. It is not therapy, legal advice or mediation.

Screens

The rules it keeps

  • If the rewrite fails, nothing is sent. The original never reaches the other person.
  • The sender approves every rewrite. Edits are checked again.
  • Both people know messages are rewritten, and every message says so.
  • Originals are deleted once the message is sent or dropped. Message text never goes into a log.
  • Chats are deleted 30 days after they close.

Quick install

You need Node.js 24 or newer.

git clone __REPO_URL__.git
cd Tactful
npm install
npm run build
npm start

Open http://127.0.0.1:3000, start a conversation, and open the invite link in a second browser window to be the other person.

To run the tests: npm test. To put it on a Linux server with a service and HTTPS, see the README.

Where it stands. It works end to end, with automated tests. The rewrite runs on a free local rewriter made of simple rules, so you can try everything without a key. A Claude provider is written but hasn't been tried on the real API yet. There's no live demo to click: the app needs a server and a database, so it can't run as a static page.
